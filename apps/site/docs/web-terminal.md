# The terminal in your browser

**Terminal** (`g t`) opens real shells in the web interface: on this computer, in a project's folder, or on one of your servers. For Oraknid's own text interface, see [Oraknid in a terminal](terminal.html).

## Turning it on

The terminal is **off** until you turn it on: it is a full shell as you, so anyone with a paired, unlocked device could use it. Turn it on from the Terminal page itself, or in **Settings → Security**; both ask first and say what it means.

## Opening a terminal

**New terminal** shows where it can open:

- **This computer**: your login shell, in your home folder, as you.
- **A project**: the same, starting in the project's folder.
- **A server**: a shell on it over SSH, through the connection Oraknid already has (see [servers](projects.html#servers)).

Terminals sit in tabs. Show them **one at a time**, **side by side**, or in a **grid** of two by two. Select text to copy it; **Ctrl Shift V** pastes. A terminal closes when you close its tab or leave the page; nothing keeps running after.

## Keys

The browser keeps **Ctrl Shift T** and **W** for itself, so the terminal's keys are:

| Keys | Does |
| :-- | :-- |
| Ctrl Shift Enter | New terminal |
| Ctrl Shift X | Close this terminal |
| Ctrl Shift ← / → | Previous / next terminal |
| Ctrl Shift 1 … 9 | Go to that terminal |
| Ctrl Shift D | Side by side |
| Ctrl Shift G | Grid |
| Ctrl Shift F | One at a time |

## In the log

Every terminal opened is in the audit log (**Logs**): which device, on what, when, and whether it was away from home. What you type is never recorded.

## Away from home

Through The Nest, the terminal opens only on a device with **full rights**, on a channel of its own, end-to-end encrypted like the rest. See [Your phone, from anywhere](phone.html).
