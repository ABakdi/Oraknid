# Finding your way

Oraknid has many pages; you never have to hunt for one. Jump with the keyboard or the command palette, read this guide inside the app, or ask the helper to show you.

## The command palette

Press **Ctrl K** (**⌘K** on a Mac), or the search box at the top. Type a few letters: the search forgives skipped letters, so `nwk` finds **New work**. It finds:

- **Pages**: every page in the sidebar, and every page of this guide.
- **Things**: projects, jobs (by name or description), servers, Legs, models, chats, skills, inbox items and GitHub repositories.
- **Controls**: new work, a new chat, pause, resume or cancel a job, approve or deny an inbox item, open a terminal, check for updates.

With nothing typed, the palette starts with what you opened recently. **Enter** opens or runs the one chosen; what can't be taken back (cancelling a job) asks once more.

## Keyboard

Single keys work whenever you aren't typing in a field:

| Keys | Does |
| :-- | :-- |
| ? | Every shortcut |
| Ctrl K | The command palette |
| n | New work |
| [ | Fold or unfold the sidebar |
| g then a key | Go to a page: `o` Overview, `p` Projects, `r` Repos, `i` Inbox, `l` Legs, `e` Models, `c` Chats, `s` Servers, `t` Terminal, `m` Mail, `y` Cloud storage, `k` Skills, `d` Docs, `,` Settings |
| 1 … 9 | That tab, on a page with tabs |

## The guide inside Oraknid

**Docs** (`g d`) is this guide, inside Oraknid: it reads the same offline and through The Nest. The pages are listed beside the one open; **Search the guide** finds headings and text, with a snippet of each place; every heading has a link of its own; **Previous** and **Next** are at the end. **Ask the helper about this** opens the helper with that page in mind.

## Ask the helper to show you

Ask the [helper](chats.html) where something is ("where do I turn the terminal on?"): it opens the page and rings the control with a short note, opening the menu or dialog that holds it.

## Going back

Everything you open from somewhere has a back control before its title, which goes back where you came from. Every dialog closes with **Esc** and has a ✕. On a small screen, the bar at the bottom holds Overview, Projects, Inbox, Legs and **More**, which has every other page.
